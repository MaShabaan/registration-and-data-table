# Registration & Data Table Project

This project contains two interactive JavaScript exercises.

## Part 1 – Registration Form (`validation.html`)

A registration form with client-side JavaScript validation for:
- **Name** – required, at least 3 characters
- **Email** – required, must be a valid email format
- **Password** – required, minimum 8 characters
- **Confirm Password** – must match the password
- **Age** – required, must be a whole number between 18 and 120

Each field displays an error message right below it when invalid. The form cannot be submitted if any field is invalid.

## Part 2 – Data Table (`data.html`)

- Displays an array of objects (people with name, age, city) as a table.
- Table rows are built dynamically with JavaScript.
- **Live search** filters rows as the user types (by name, city, or age).
- **Sort buttons** sort by name or by age (click again to reverse order).

## How to run

Just open `index.html` in any modern browser, or enable GitHub Pages in the repository settings.
